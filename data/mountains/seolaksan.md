# 설악산

> 강원 · 강원특별자치도 속초시·인제군·양양군 · 해발 1708.1m · 산림청 100대 명산 / 블랙야크 명산100 / 한국의산하 인기명산 100 / 월간산 100대 명산

## 개요

설악산은 강원특별자치도 속초시·인제군·양양군·고성군에 걸친 해발 1708.1m의 산으로, 주봉은 대청봉이다. 한라산·지리산에 이어 남한에서 세 번째로 높으며 국립공원이자 유네스코 생물권보전지역으로 지정되어 있다. 천불동계곡, 공룡능선, 울산바위, 비룡폭포 등 수려한 암릉과 계곡, 가을 단풍으로 국내 최고의 명산으로 꼽힌다.

## 대표·유명 코스

공식 탐방안내와 기존 산별 자료를 바탕으로 정상 접근, 능선 종주, 경관 탐방을 편집 선정했습니다. 방문객 수에 따른 인기 순위는 아닙니다.

기존 자료 선정 코스는 산 단위 참고자료에 기반하며, 개별 코스의 인기도를 별도로 검증하지 않았습니다.

### 소공원-흔들바위-울산바위

- 선정 유형: 대표 들머리·정상 접근
- 주요 동선: 소공원 → 신흥사 → 흔들바위 → 울산바위
- 특징: 흔들바위와 울산바위의 암벽 경관을 연결하는 탐방 코스.
- 근거: 공식 코스 안내 확인
- [국립공원공단 · 울산바위코스](https://www.knps.or.kr/front/portal/visit/visitCourseGuide.do?parkId=120400&vcursId=120400V003) (확인: 2026-10-03)

### 공룡능선 종주

- 선정 유형: 능선·연계 산행
- 주요 동선: 소공원 → 비선대 → 마등령 → 공룡능선 → 희운각 → 대청봉 → 오색
- 특징: 공룡능선의 암릉 경관을 지나는 장거리 종주. 공단 안내의 오색 하산 동선을 수록했습니다.
- 근거: 공식 코스 안내 확인
- [국립공원공단 · 공룡능선코스](https://www.knps.or.kr/front/portal/visit/visitCourseGuide.do?parkId=120400&vcursId=120400V016) (확인: 2026-10-03)

### 오색-대청봉

- 선정 유형: 대표 들머리·정상 접근
- 주요 동선: 남설악탐방지원센터(오색) → 설악폭포 → 대청봉
- 특징: 오색에서 설악산 주봉 대청봉에 접근하는 코스.
- 근거: 공식 코스 안내 확인
- [국립공원공단 · 대청봉코스(오색)](https://www.knps.or.kr/front/portal/visit/visitCourseGuide.do?parkId=120400&vcursId=120400V012) (확인: 2026-10-03)

### 설악동-천불동-대청봉-오색

- 선정 유형: 대표 들머리·정상 접근
- 주요 동선: 소공원 → 비선대 → 천불동계곡 → 희운각 → 대청봉 → 오색
- 특징: 천불동계곡의 경관과 대청봉을 연결하는 종주.
- 근거: 공식 코스 안내 확인
- [국립공원공단 · 대청봉코스(설악동)](https://www.knps.or.kr/front/portal/visit/visitCourseGuide.do?parkId=120400&vcursId=120400V015) (확인: 2026-10-03)

### 한계령-대청봉-소공원

- 선정 유형: 대표 들머리·정상 접근
- 주요 동선: 한계령 → 서북능선 → 대청봉 → 비선대 → 소공원
- 특징: 서북능선에서 대청봉을 거쳐 설악동으로 내려가는 종주.
- 근거: 공식 코스 안내 확인
- [국립공원공단 · 대청봉코스(한계령)](https://www.knps.or.kr/front/portal/visit/visitCourseGuide.do?parkId=120400&vcursId=120400V014) (확인: 2026-10-03)

## 교통

외설악은 속초시외버스터미널에서 설악동 소공원행 시내버스(7·7-1번) 이용. 오색·한계령은 동서울·양양 방면 버스로 오색리 하차. 자가용은 소공원 공영주차장, 오색·한계령 주차장 이용.
