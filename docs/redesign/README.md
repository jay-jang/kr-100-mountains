# 지도 우선 재구성 — 설계 기록 (2026-10-13)

모바일에서 지도가 첫 화면이 되도록 앱 구조를 다시 짠 과정의 기록이다.
같은 브리프로 세 설계자(A·B·C)가 서로의 안을 보지 않고 제안서를 쓰고, 이를 조율한 뒤
B·C가 조율안을 다시 검토해 최종안을 확정했다. 구현 뒤에는 실제 화면을 B·C에게 다시 보여 주고
비평을 받아 고쳤다.

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | `proposal-a.md` · `proposal-b.md` · `proposal-c.md` | 독립 제안서 3편 |
| 2 | `references.md` | 실제로 열어 확인한 UI 레퍼런스와 적용 체크리스트(24개 규칙) |
| 3 | `spec-v1.md` | 1차 조율안 — 쟁점 24개를 A·B·C 입장과 함께 표로 결정 |
| 4 | `review-b.md` · `review-c.md` | 조율안에 대한 B·C의 2라운드 검토(동의·조건부·반대) |
| 5 | `spec-final.md` | 2라운드 반영 최종안(구현 기준). 맨 아래에 v1 → v2 변경표 |
| 6 | `critique-b.md` · `critique-c.md` · `round3.md` | 구현된 화면에 대한 B·C의 3라운드 비평과 처리 결과 |

요약
- 첫 화면 = 전국 지도. 목록·산·경로·걷기길은 지도 위 시트 하나로 올라온다(홈 대시보드·목록/지도 토글 폐지).
- 길을 지도에 띄우는 입구는 하나: 경로 행(또는 지도 위 선)을 누르면 선이 그려지고 같은 시트에 수치·고도·길찾기·GPX가 따라온다.
- 정상 등정 외에 산 주변의 둘레길·숲길·능선 종주 노선(OpenStreetMap)을 산 시트 '주변 길' 탭, 걷기길 모드, 확대 시 지도 레이어로 보여 준다.
- 고급·저우선 기능(여러 경로 겹쳐 보기, GPX 열기, 경로 계획, 경로 따라가기, 등산로망 실시간 조회, 추천 묶음, 대표 코스 모음 등)은 설정에서 켜고 끈다.
