24장 전체와 구현 코드를 확인했다. 파일은 수정하지 않았다. 아래 동작 문제는 코드 대조 결과이며, 실제 브라우저 재현 검증은 하지 않았다. 체크리스트와 충돌하는 상단 내비게이션·실측 peek 높이는 최종안의 의도적 변경으로 보았다.

**1. 사용자 요구별 평가**

| 요구 | 잘 된 점 | 부족한 점 |
|---|---|---|
| 모바일 공간 | 검색·모드·지도 조작을 압축하고 긴 내용은 시트에 모았다. | 첫 화면에는 목록 행이 전혀 없어 목록의 존재와 펼치는 방법이 약하게 드러난다. |
| 지도 우선 | 모바일 지도와 데스크톱 400px 패널 구성이 일관된다. | 시트를 펼치면 선택 경로의 들머리가 가려져 지도와 정보를 함께 읽기 어렵다. |
| 주변 하이킹·트레킹 | 주변 반경, 종류, 부분·전체 길이와 독립 걷기길 화면을 제공한다. | 순환·편도 미확인 상태가 설명 없이 빠지고, 지도 이동 후 재검색도 접힌 시트에서는 발견하기 어렵다. |
| AI스럽지 않음 | 행·구분선·절제된 색과 SVG가 정보 중심 인상을 만든다. | 긴 코스명을 한 줄 메타데이터에 압축하면서 시간·난이도까지 잘리는 화면이 있다. |
| 쉬운 조작 | 확대·축소, 명시적 길찾기·GPX 버튼, 탭 선택 표시가 분명하다. | 탭으로 시트를 충분히 접을 수 없고, ×와 뒤로가기의 이동 단계가 다르다. |
| 저우선 기능 토글 | 경로 도구를 기본 화면에서 숨기고 설정으로 분리했다. | 대표 코스 모음 입구가 목록 끝에 있어 켠 기능을 찾기 어렵다. |

**2. 고쳐야 할 문제 상위 10개**

1. **높음 · `02-m-list-half.png`, `10-m-info-tab.png` — 탭으로 접기 불가.**  
   그래버를 누르면 half↔full만 반복한다. peek·min으로 돌아가려면 드래그나 방향키가 필요하고, 목록에는 보이는 접기 버튼도 없다. 그래버 탭으로 모든 단계를 순환시키거나 44px짜리 ‘접기/지도만 보기’를 제공한다. **근거: 체크리스트 5·11, 최종안 §4.**

2. **높음 · `07-m-route-sheet.png`, `12-m-walk-sheet.png` — ×가 상위 화면을 건너뛴다.**  
   우측 ×(약 x362)는 경로에서 목록으로 두 단계 이동하고, 산에서 연 걷기길에서도 산을 건너뛴다. 경로의 Esc는 산으로 돌아가므로 같은 화면의 종료 동작이 불일치한다. ×·Esc·브라우저 뒤로가기를 모두 한 단계 이동으로 통일한다. **근거: 최종안 §2·§12.**

3. **높음 · `08-m-route-half.png` — 시트 확장 후 들머리가 가려진다.**  
   시트가 y458부터 덮지만 경로는 peek에서 맞춘 위치를 유지한다. `07`에서 보이던 들머리·라벨이 사라진다. 높이 변경 완료 시 선택 경로를 현재 가시 영역에 다시 맞추고, 사용자가 직접 지도를 움직인 상태에서는 ‘경로 전체 보기’를 제공한다. **근거: 최종안 §3·§8.**

4. **높음 · `03-m-filter-modal.png`, `05-m-mountain-sheet.png` — 실제 터치 영역이 44px에 못 미친다.**  
   필터의 시간·거리 선택은 높이 36px, 등정 버튼도 약 36px이며 그래버 버튼은 28px다. 상단 모드 버튼의 확장용 가상요소는 부모의 `overflow:hidden`에 잘린다. 가상요소 대신 버튼·선택 입력 자체를 최소 44px로 만들고 인접 영역을 분리한다. **근거: 체크리스트 10, 최종안 §12.**

5. **높음 · `10-m-info-tab.png`, `05-m-mountain-sheet.png` — 과거 위험 기록이 현재 경고처럼 집계된다.**  
   ‘주의 위험구간 2건’에 2014-10 산행기 내용도 포함된다. ‘교차검증’은 최신 상태 확인으로 오해하기 쉽고, 날짜 없는 항목도 있다. 경고 줄을 ‘위험 관련 자료 2건’으로 표시하고 각 항목에 자료 기준일·확인일을 구분한다. 오래되거나 날짜 없는 자료에는 ‘현재 상태 미확인’을 붙인다. **근거: 최종안 §1.4·§7.**

6. **중간 · `01-m-first-screen.png`, `18-m-dark-first.png`, `21-d-first.png` — 전국 축척에서 마커가 과밀하다.**  
   모바일 x110–290, y250–550 부근에 삼각형과 44px 터치 영역이 겹친다. 코드의 ‘이 근처 산’ 선택창이 오선택은 완화하지만 분포·개수를 읽기는 어렵다. 전국 축척에서는 숫자 클러스터로 묶고, 탭하면 해당 범위를 확대한다. **근거: 체크리스트 21.**

7. **중간 · `12-m-walk-sheet.png`, `24-d-walk.png` — 순환·편도가 설명 없이 누락된다.**  
   길이와 부분 구간은 표시하지만 왕복 계획에 필요한 노선 형태가 빠진다. 코드도 `loop`가 없으면 문구를 생략한다. 옛 자료에는 ‘순환 여부 미확인’을 표시하고, 전체 노선의 형태와 현재 표시 구간의 시작·끝을 구분한다. **근거: 최종안 §9.**

8. **중간 · `11-m-walk-mode.png` — 지역 재검색 버튼이 지도에서 발견되지 않는다.**  
   ‘이 지역 다시 찾기’가 y600 부근의 목록 본문에 있다. peek에서는 숨겨지므로 지도를 옮겨도 사용자는 기존 결과를 보고 있다는 사실을 놓친다. 지도 상단 중앙에 버튼을 띄우고 결과 수 옆에 ‘이전 검색 영역’을 표시한다. **근거: 체크리스트 8, 최종안 §9.**

9. **중간 · `21-d-first.png` — 코스명이 시간·난이도를 밀어낸다.**  
   운악산 행(y502–569)의 긴 대표 코스명 뒤가 잘려 왕복 시간·난이도를 읽을 수 없다. 코스명만 말줄임하고 시간·난이도는 별도 고정 영역에 둔다. 모바일에서도 같은 정보를 보장한다. **근거: 체크리스트 18, 최종안 §5.**

10. **중간 · `02-m-list-half.png`, `08-m-route-half.png`, `09-m-nearby-walks-tab.png` — 지도 출처가 시트 뒤에 숨는다.**  
    peek에서는 보이지만 half 화면의 왼쪽 지도 하단에는 OSM 출처가 없다. 지도 컨테이너가 peek 기준으로 끝나기 때문이다. 출처 컨트롤도 현재 시트 윗변에 맞춰 이동시키고, 공간이 부족하면 출처를 여는 정보 버튼을 남긴다. **근거: 체크리스트 23.**

**3. 최종안과 다른 구현**

- **§2·§12:** 경로·걷기길의 ×가 한 단계 복귀 대신 목록으로 건너뛴다.
- **§4:** full 상단 여백은 64px 대신 코드의 `TOP_GAP=72`를 사용한다.
- **§4:** 헤더뿐 아니라 본문 스와이프도 시트 높이를 변경해 내용 스크롤과 시트 확장이 섞인다.
- **§8:** ‘선택한 경로’ 줄은 헤더가 아닌 본문 sticky 영역에 있어 peek에서는 보이지 않는다.
- **§9:** 순환·편도 값이 없는 자료는 미확인 표시 없이 생략한다. 전국 수집 진행 자체와는 별개인 표시 문제다.
- **§10:** 설정을 켠 대표 코스 모음 입구가 목록 헤더 대신 목록 끝에 배치된다.
- **§12:** 그래버·일부 버튼·선택 입력의 실제 높이가 44px 기준을 충족하지 못한다.
