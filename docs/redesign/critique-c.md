# 3라운드: 구현 결과 비평 리포트

---

## 1. 사용자 요구 6가지 평가

1. **모바일 공간**
   - **잘 된 점**: 지도를 바닥에 깔고 단일 바텀시트(peek·half·full)를 얹어 390×844 화면에서 지도를 최소 70% 이상 확보하면서 가로 스크롤 없이 밀도 있게 배치했다.
   - **부족한 점**: 전국 축척(01)에서 149개 산 마커가 클러스터링 없이 겹쳐 수도권·강원권 마커 터치가 어렵고, 시트 높이 단계 전환 시 peek 복귀가 매끄럽지 않다.

2. **지도 우선**
   - **잘 된 점**: 모든 화면 전환(목록·산·경로·걷기길)에서 지도를 파괴하지 않고 시트 내용과 선 오버레이만 갈아 끼워 탐색 흐름이 끊기지 않는다.
   - **부족한 점**: 검색 제안에서 산을 고르거나 라우트를 이동해도 상단 검색창에 검색어('지리')가 그대로 남아(05, 07) 지도의 맥락과 검색창 상태가 어긋난다.

3. **주변 하이킹/트레킹**
   - **잘 된 점**: 산 시트의 '주변 길' 탭에서 반경(5·10·15km) 필터링과 지도 선 표출, 전국 걷기길 독립 모드 및 상세 시트 연계가 완결성 있게 동작한다.
   - **부족한 점**: 걷기길 모드(11) 상단 칩에서 '필터'가 통째로 숨겨지고, 목록에 순수 둘레길이 아닌 설악산 등산로(탐방로) 노선이 상위에 섞여 나온다.

4. **AI스럽지 않음**
   - **잘 된 점**: 이모지·보라색 그라데이션·유리 블러를 배제하고 국립공원 5단계 난이도 색상 및 정직성 배지(교차검증/계산 경로/공단 확인)를 건조하고 사실 위주로 배치했다.
   - **부족한 점**: 상단 설정 버튼 아이콘(01, 14, 21)이 톱니바퀴 대신 8방향 햇살 모양으로 그려져 다크·라이트 테마 변경 버튼으로 심각하게 오인된다.

5. **쉬운 조작**
   - **잘 된 점**: 주요 버튼과 목록 행이 44×44px 터치 타깃을 충족하며 ‹, Esc, [×]를 통한 계층적 히스토리 복원이 일관되게 동작한다.
   - **부족한 점**: 경로를 확인한 후 산 시트로 복귀했을 때 지도에 남은 선을 제어할 "선택한 경로" 고정 줄(05)이 누락되어 선택 해제나 재확인이 불편하다.

6. **저우선 기능 토글**
   - **잘 된 점**: 경로 겹쳐보기·GPX 열기·경로 계획 등 복잡한 기능을 설정에서 기본 OFF로 숨겨 일반 사용자 화면의 시각적 피로도를 성공적으로 낮췄다.
   - **부족한 점**: 설정 스위치 조작 시 체크리스트가 요구한 '2~3초 시각 토스트 및 되돌리기'가 없고 레이어 모달에서 등산로 토글이 누락되었다.

## 2. 고쳐야 할 문제 상위 10개

1. **상단 검색창 검색어 잔류 버그**
   - **심각도**: 높음
   - **화면**: `05-m-mountain-sheet.png`, `07-m-route-sheet.png`, `08-m-route-half.png`
   - **문제**: 검색창(`.tb-input`, y:8~56)에서 "지리"를 입력해 설악산 항목을 선택했으나, 설악산 상세 및 경로 시트 화면에서도 검색창에 "지리"와 [✕] 버튼이 그대로 남아 있다. 화면은 설악산인데 검색창은 지리산으로 필터링된 것처럼 보여 사용자가 심각하게 혼동한다.
   - **해결 방안**: `src/shell.js`의 `open()`에서 라우트가 목록(`list`)이 아닌 산(`mountain`)이나 걷기길(`walk`)로 바뀔 때 `ctx.search.setValue('')`를 호출해 검색창을 플레이스홀더 상태로 초기화한다.
   - **근거**: 최종안 §6, 체크리스트 규칙 19.

2. **전국 축척 산 기호 마커 겹침·터치 불가**
   - **심각도**: 높음
   - **화면**: `01-m-first-screen.png`, `18-m-dark-first.png`, `21-d-first.png`
   - **문제**: 전국 축척에서 149개 산 마커(`.mk`)가 클러스터링 없이 전부 개별 삼각형으로 렌더링되어 서울·경기·강원 영서 지역에서 마커 수십 개가 뭉쳐 특정 산을 짚어 터치할 수 없다.
   - **해결 방안**: 줌 레벨이 낮은 전국/광역 뷰에서는 겹치는 마커를 권역/반경 기준 숫자 클러스터로 묶고 탭 시 해당 영역으로 확대되도록 마커 클러스터링을 적용한다.
   - **근거**: 체크리스트 규칙 21, Map UI Patterns `Cluster marker`.

3. **설정 아이콘의 테마 버튼 오인 형태**
   - **심각도**: 높음
   - **화면**: `01-m-first-screen.png`, `02-m-list-half.png`, `21-d-first.png`
   - **문제**: 상단 바 우측 설정 버튼(`.tb-btn.icon`, x:334, y:8)의 SVG 아이콘이 중심 원과 8개 방사선으로 그려진 전형적인 태양/햇살 모양(`☼`)이다. 환경설정이 아닌 '다크/라이트 모드 전환 버튼'으로 잘못 읽힌다.
   - **해결 방안**: `src/icons.js`의 `settings` 패스를 6~8개의 명확한 톱니를 가진 표준 기어(`⚙`) 형상으로 수정한다.
   - **근거**: 최종안 §3, 체크리스트 규칙 24, NN/g `Icon Usability`.

4. **산 시트 복귀 시 "선택한 경로" 고정 줄 누락**
   - **심각도**: 높음
   - **화면**: `05-m-mountain-sheet.png`
   - **문제**: 경로 시트에서 산 시트로 복귀했을 때 지도상에는 고른 경로 선이 남아 있지만, 시트 peek 헤더에 "선택한 경로: 오색–대청봉 [보기][×]" 고정 바가 노출되지 않아 현재 표시된 선이 무엇인지 확인하거나 선을 해제하기 어렵다.
   - **해결 방안**: 최종안 §7 목업 명세에 따라 `selBar`를 `mtnHeader` 타이틀 바로 아래 고정 행으로 배치하여, 경로를 고른 뒤 복귀 시 항상 표시되고 [보기]와 [×]를 제공하도록 수정한다.
   - **근거**: 최종안 §7(목업 라인 81), §8 라인 109, 2라운드 반영 표(제기 C).

5. **시트 그래버 탭 순환 시 peek 복귀 불가**
   - **심각도**: 중간
   - **화면**: `01-m-first-screen.png`, `02-m-list-half.png`, `06-m-mountain-full.png`
   - **문제**: `src/sheet.js` 클릭 이벤트가 `detent === 'full' ? 'half' : detent === 'half' ? 'full' : 'half'`로만 토글되어, 시트가 펼쳐진 상태에서 그래버를 탭해 지도를 넓게 볼 수 있는 `peek` 단계로 되돌릴 수 없다.
   - **해결 방안**: 그래버 탭 시 `peek → half → full → peek` 순서로 순환(`ORDER[(idx + 1) % ORDER.length]`)하도록 변경한다.
   - **근거**: 최종안 §4 라인 56, 체크리스트 규칙 4.

6. **걷기길 모드 상단 칩 숨김 오류 및 등산로 혼입**
   - **심각도**: 중간
   - **화면**: `11-m-walk-mode.png`
   - **문제**: 걷기길 모드 진입 시 [필터] 칩까지 숨겨져 상단 칩 줄에 [명산|걷기길]만 남는다(최종안은 3번째 [둘레길 있는 산]만 숨김). 또한 목록 상단에 둘레길이 아닌 일반 정상 코스("오색-대청봉", "희운각 대피소-소청봉")가 섞여 나온다.
   - **해결 방안**: `src/shell.js`의 `filterChip.hidden = walk;`를 제거하고, 걷기길 모드 기본 목록에서 정상 코스(`kind === 'trail'`)를 제외하고 순수 둘레·장거리·마루금·숲길을 우선 노출한다.
   - **근거**: 최종안 §3 라인 31, §7 라인 87, §9 라인 117.

7. **레이어 모달 내 등산로 토글 누락 및 썸네일 부재**
   - **심각도**: 중간
   - **화면**: `16-m-layers-modal.png`
   - **문제**: 레이어 모달에 '걷기길 선' 스위치만 있고 핵심 레이어인 '등산로 선' 온오프 토글이 누락되어 있다. 배경지도 또한 썸네일 없는 텍스트 버튼(`[일반][지형][위성]`)으로 제공되어 변경 효과를 미리 알기 어렵다.
   - **해결 방안**: [표시] 섹션에 '등산로 선 표시' 스위치를 추가하고, 배경지도 선택 영역에 3종 썸네일 라디오 버튼을 적용한다.
   - **근거**: 체크리스트 규칙 14, 최종안 §3 라인 46.

8. **검색 제안 팝업에서 '걷기길' 묶음 누락**
   - **심각도**: 중간
   - **화면**: `04-m-search-suggest.png`
   - **문제**: "지리" 검색 시 명산 5건, 코스 2건만 제안되고 "지리산둘레길" 같은 전국 걷기길 묶음이 제안 목록에서 누락되어 있다(`loadWalkIndex()` 비동기 로딩 지연 또는 매칭 누락).
   - **해결 방안**: 검색창 포커스 시 걷기길 색인을 우선 확보하고, 제안 팝업에 '명산 / 코스 / 걷기길' 3단 묶음이 안정적으로 표출되도록 수정한다.
   - **근거**: 최종안 §6 라인 71.

9. **설정 변경 시 시각적 토스트 및 되돌리기 누락**
   - **심각도**: 중간
   - **화면**: `14-m-settings.png`
   - **문제**: 설정 화면 스위치 토글 시 화면에 나타나는 시각적 피드백 없이 숨은 `aria-live` 문자열만 갱신된다. 사용자가 설정 저장을 시각적으로 확인하기 어렵고 즉시 원복하기 번거롭다.
   - **해결 방안**: 스위치 토글 시 하단에 2~3초간 "산 이름 표시가 켜졌습니다. [되돌리기]" 형태의 시각적 토스트 바를 띄운다.
   - **근거**: 체크리스트 규칙 15, KRDS 모바일 설정 가이드.

10. **목록 시트 행 대표 코스 거리(km) 누락**
    - **심각도**: 낮음
    - **화면**: `02-m-list-half.png`, `21-d-first.png`
    - **문제**: 목록 행 메타 정보에 "수도권 · 화악터널-중봉 코스 왕복 4.5시간 · 보통"으로 나와 대표 코스의 거리 수치가 빠져 있다. 코스의 물리적 규모를 파악하기 어렵다.
    - **해결 방안**: "화악터널-중봉 코스 · 6.5km · 왕복 4.5시간 · 보통" 형태로 거리 단위를 포함해 표준화한다.
    - **근거**: 체크리스트 규칙 18, 최종안 §5 라인 64.

## 3. 최종안(`spec-final.md`)과 다르게 구현된 곳

1. **상단 바 설정 아이콘 형상**: 최종안 §3의 톱니바퀴(`⚙`) 대신 태양/햇살 모양(`☼`)으로 구현됨.
2. **산 시트 복귀 시 고정 바**: 최종안 §7의 "선택한 경로: [이름] [보기][×]" 헤더 고정 줄이 누락됨.
3. **상단 검색창 상태 초기화**: 최종안 §6과 달리 화면 전환 후에도 직전 검색어('지리')가 검색창에 영구 잔류함.
4. **걷기길 모드 상단 칩 노출 규격**: 최종안 §3은 3번째 칩([둘레길 있는 산])만 숨기도록 규정했으나, 구현에서는 2번째 [필터] 칩까지 일괄 숨김 처리됨.
5. **걷기길 모드 종류 필터 명칭 및 구성**: 최종안 §9의 `[숲길·옛길]` 대신 `[숲길]`로 축소되었고, 명세에 없던 `[탐방로]` 칩이 추가됨.
6. **시트 그래버 클릭 순환**: 최종안 §4의 `peek → half → full → peek` 순환 대신 `half ↔ full` 왕복으로만 동작하여 peek 복귀가 불가함.
7. **레이어 모달 등산로 토글 및 썸네일**: 최종안 §3 및 규칙 14의 배경지도 썸네일 라디오와 등산로 오버레이 스위치가 누락됨.
8. **설정 화면 피드백 방식**: 최종안 §10 및 규칙 15의 2~3초 시각 토스트와 개별 되돌리기 액션이 누락됨.
9. **전국 축척 마커 클러스터링**: 최종안 §3 및 규칙 21과 달리 149개 마커 전체를 개별 렌더링하여 광역 뷰에서 심한 중첩 발생.
