# 3라운드 — 구현 결과 비평과 조율 (2026-10-13)

구현된 화면 24장(모바일 라이트·다크, 데스크톱)과 코드를 B·C에게 보여 주고 비평을 받았다(`critique-b.md`, `critique-c.md`).
A의 관점(최종안의 원안 대부분)과 레퍼런스 체크리스트를 기준으로 아래와 같이 처리했다.

| 지적 | 제기 | 처리 |
|---|---|---|
| 그래버 탭으로 peek에 돌아갈 수 없다 | B·C | **수용** — 탭 순환을 peek→half→full→peek로 |
| 전국 축척에서 산 기호 149개가 겹친다 | B·C | **수용** — 보이는 폭 200km 초과면 화면 34px 안의 기호를 숫자 묶음으로, 누르면 그 범위로 확대(선택한 산은 묶지 않음) |
| 설정 아이콘이 해 모양이라 테마 버튼으로 읽힌다 | C | **수용** — 톱니가 있는 윤곽으로 다시 그림 |
| 검색 제안을 고른 뒤에도 입력한 글자가 남는다 | C | **수용** — 목록의 원래 검색어로 되돌림 |
| 시트를 펼치면 고른 경로·들머리가 가려진다 | B | **수용** — 사용자가 지도를 직접 옮기지 않았다면 시트 높이가 바뀐 뒤 마지막 맞춤을 새 여백으로 다시 적용 |
| 일부 터치 대상이 44px 미만(select·작은 버튼·세그먼트 확장 영역·그래버) | B | **수용** — select·작은 버튼 44px, 세그먼트의 overflow를 풀어 확장 영역이 잘리지 않게, 그래버 36px(헤더 전체가 드래그 영역) |
| 걷기길 모드의 '이 지역 다시 찾기'가 목록 안에 숨어 있다 | B | **수용** — 지도 위 가운데 버튼으로 |
| 목록 행에서 긴 코스명이 시간·난이도를 밀어내고, 거리가 없다 | B·C | **수용** — 행을 2줄 메타로(권역 / 코스명·거리·왕복·난이도), 코스명만 말줄임 |
| half에서 지도 출처가 가려진다 | B | **수용(OSM)** — 출처를 시트 윗변에 맞춰 이동. 카카오 로고는 지도 안에 고정되어 옮길 수 없음 |
| 오래된 위험 기록이 현재 경고처럼 보인다 | B | **수용** — "자료" 표기, 항목마다 자료 기준일, 오래되었거나 날짜가 없으면 "현재 상태 미확인" |
| 걷기길 '전체'에 정상 코스(탐방로) 노선이 섞인다 | C | **수용** — '전체'는 걷기길만, 탐방로는 [탐방로] 칩에서만 |
| 검색 제안에 걷기길 묶음이 빠진다 | C | **수용** — 전국 걷기길 목록을 한가할 때 미리 받음 |
| 대표 코스 모음 입구가 목록 끝에 있다 | B | **수용** — 목록 헤더로 |
