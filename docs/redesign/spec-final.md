# 최종 설계안 (v2) — 지도 한 장 위의 시트

세 설계안(A·B·C) → 조율안 v1 → B·C의 2라운드 검토를 반영한 **구현 기준 문서**다.
결정 근거 표는 `spec-v1.md` 1장, 2라운드에서 바뀐 것은 맨 아래 "2라운드 반영"에 정리했다.

## 1. 원칙
1. 지도는 바닥이다. 목록·산·경로·걷기길은 그 위의 시트 하나로 올라온다(기록·설정·대표 코스 모음만 전체 페이지).
2. 길 하나에 동작 하나: **경로 행(또는 지도 위 선)을 누르면 그 선이 그려지고 같은 시트에 수치·고도·길찾기·GPX가 따라온다.**
3. 같은 기능의 입구는 하나. 저우선·고급 기능은 설정에서 켠다(입구만 숨김, 링크로 들어온 내용은 열림).
4. 정직성 표시는 작게, 늘 데이터 바로 옆에(생성 방식·검증 수준·출처·확인일).
5. 장식 없음: 이모지·그라데이션·글래스·슬로건·카드 그리드·장식 통계 금지.

## 2. 라우트
| 해시 | 화면 | 비고 |
|---|---|---|
| `#/`, `#/map?…` | 지도 + 목록 시트 | `region,list,all=4,q,hiked=1|0,sort=near,easy=1,hours,distance,focus,mode=walk,walkkind,dulle=1` |
| `#/m/<id>` | 지도 + 산 시트 | `?tab=courses|walks|info`, `?r=5|10|15`(주변 반경) |
| `#/m/<id>?route=<key>` | 지도 + 경로 시트 | key: `t:<trailIndex>` · `c:<courseId>` · `o:<osm relation id>`(OSM 탐방로). `?course=<courseId>`는 `route=c:<id>` 별칭 |
| `#/walk/<rid>` | 지도 + 걷기길 시트 | `?from=<mountainId>`(돌아갈 산) |
| `#/track`, `#/stats` | 내 기록(전체 페이지) | |
| `#/settings` | 설정(전체 페이지) | |
| `#/courses?q=&region=` | 대표 코스 모음(전체 페이지, 20개씩 더 보기) | 설정과 무관하게 링크로는 열림 |
- 지도 라우트 사이 이동은 지도를 파괴하지 않고 시트만 바꾼다. 전체 페이지로 가면 지도 셸은 숨김(추적·요청 중단), 돌아오면 `relayout()`.
- 앱 안에서 연 화면은 `history.pushState({kr100:{depth}})`. [×]·Esc = 앱 안 기록이 있으면 `history.back()`, 직접 들어온 링크면 상위 화면으로 `replace`(경로→산→목록, 걷기길→from 산 또는 목록). 시트 **높이** 변화는 기록에 쌓지 않는다.
- 목록 필터는 `replaceState`로 URL에 쓴다(기존 방식).

## 3. 지도 셸 (모바일 390×844)
```
┌──────────────────────────────────────┐
│ [ 산·코스·걷기길 검색      ][기록][⚙]│  상단 바: 검색 48 높이, 버튼 44×44 (기록=글자, 설정=아이콘+aria-label)
│ [명산│걷기길] [필터 2] [둘레길 있는 산]│  칩 줄 36(터치 44) — 걷기길 모드에서 3번째 칩은 숨김
│                                      │
│              지도                [+] │  오른쪽 묶음(위→아래): + − 레이어 내위치, 44×44 간격 8
│       △        ▲       △        [−] │  묶음 아래끝 = 시트 윗변 − 12px, 시트 full이면 숨김
│                              [레이어]│
│ © OpenStreetMap          [내 위치]  │
├──────────────────────────────────────┤
│               ────                   │  그래버 <button>
│ 명산 149곳 · 등정 12        가까운 순 │  목록 시트 헤더(peek) — 가까운 순 정렬 토글은 여기
└──────────────────────────────────────┘
```
- 지도 컨테이너: `top:0; bottom: <현재 시트 peek 높이>`. 그래서 저작권 표시(왼쪽 아래)는 peek 위에 늘 보인다. half/full에서 가려지는 부분은 맞춤 여백으로 처리.
- 맞춤·이동 여백: `padding = {top: 116, bottom: (시트 보이는 높이 − peek) + 16, left: 16, right: 64}`. 시트가 full이면 맞춤을 미루고 접힐 때 실행.
- 확대·축소 버튼: **기본 표시**(핀치의 단일 포인터 대안), 설정에서 숨길 수 있음.
- [내 위치]: 탭 = 한 번 측정 후 이동(첫 실행에 묻지 않음). 위치가 표시되면 버튼 왼쪽에 글자 버튼 **[계속 추적]**이 나타나 명시적으로 시작·종료한다. 권한 허용된 재방문자만 조용히 측정. `position.js` 캐시 재사용.
- [레이어] 모달: 지도 종류(일반/지형/위성) · 걷기길 선 표시 · 산 이름 표시 · 권역별 색 구분 · "선 읽는 법"(선 종류 견본) · "기능 설정 ›".
- 산 기호: 미등정 △(잉크색 외곽선) / 등정 ▲(채움), 시각 16px·터치 44px. 이름 라벨은 보이는 범위 폭 ≤ 150km에서(설정 '산 이름 표시'). 권역 색은 설정 ON일 때만. 걷기길 모드에서는 산 기호 35% 투명.
- 걷기길 선(설정 '걷기길 선 표시' ON): **보이는 범위 폭 ≤ 60km**일 때 화면 안 노선을 종류색으로 얇게, 화면 중심에서 가까운 순 최대 80개. 그보다 넓으면 그리지 않고, 걷기길 모드에서는 시트에 "지도를 확대하면 길이 보입니다".
- 선택된 산/경로/걷기길 선은 위 제한과 무관하게 그린다.

## 4. 시트
- 단계: `min`(그래버만 44, "지도만 보기") · `peek` · `half` · `full`.
  - **peek 높이 = 시트 헤더의 실측 높이**(그래버 포함, 내용에 따라 다름. 목록 ≈ 84, 산 ≈ 132, 경로 ≈ 140). 고정 숫자 금지.
  - half = 가용 높이 × 0.5 (가용 = `visualViewport.height` − 상단 바 64 − safe-area).
  - full = 뷰포트 − 64 (검색 바는 보이고 **칩 줄은 덮는다**).
- 그래버 `<button aria-label="시트 크기: 중간">`: 탭/Enter/Space = 다음 단계(peek→half→full→half…), ↑/↓ = 한 단계. 드래그는 그래버+시트 헤더에서만(본문은 스크롤), 놓으면 가까운 단계, 속도 > 0.5px/ms면 진행 방향 다음 단계, 아래로 끝까지 = min. `overscroll-behavior: contain`, `touch-action`로 지도에 제스처가 새지 않게. `prefers-reduced-motion`이면 전환 애니메이션 없음.
- 높이 애니메이션은 `height` 전환(본문 스크롤이 모든 단계에서 정상 동작하게).
- 시트는 한 번에 하나. 필터·레이어는 `<dialog>` 모달(포커스 가두기·Esc·포커스 복귀, 배경 검색 비활성). 모달 위 모달 금지.
- 내용이 바뀌면(항목 선택 시에만) 포커스를 시트 제목으로. 입력 중에는 포커스를 옮기지 않는다(한글 조합 보호). 결과 수는 `aria-live="polite"`.
- 데스크톱 ≥1024: 시트 = 왼쪽 400px 패널(단계 없음, 스크롤), 상단 바는 패널 위쪽, 지도는 오른쪽. 640–1023: 바텀시트 최대 폭 560px, 왼쪽 16px.

## 5. 목록 시트(명산 모드)
- 헤더: "명산 31곳 · 등정 12"(등정 수를 누르면 `#/track`) · [가까운 순] 토글 · 적용 조건 토큰([강원 ×]) · "조건 초기화". 가까운 순이면 한 줄 "3분 전 위치 기준".
- 행(≥60px, 구분선): 이름·동명이산·해발·등정 표시 / 권역 · 대표 코스 한 줄(왕복·난이도) · 가까운 순이면 방위·거리.
- 행 탭 = 산 시트(지도는 그 산으로). 데스크톱 hover = 기호 강조.
- 설정 '추천 묶음' ON: 목록 맨 위 "인기·계절 기준 3곳".
- 검색에서 조건 밖의 산을 고르면 조건을 몰래 풀지 않는다 — 산 시트는 조건과 무관하게 열리고, 지도에는 그 산 기호가 선택 표시로 보인다.
- 필터 모달: 목록 4 + 4개 목록 모두 · 권역 6 · 등정(전체/등정/미등정) · 코스(쉬움·보통만, 왕복 시간, 코스 거리) · 둘레길·걷기길 있는 산 · 하단 [초기화] [31곳 보기](결과 수 상시). 즉시 반영.

## 6. 검색(상단 바)
- 결과를 **명산 / 코스 / 걷기길** 묶음으로 각 최대 3–5개. 명산 → 산 시트, 코스 → 경로 시트, 걷기길 → 걷기길 시트. 걷기길은 산과 무관하게 전국 노선에서 찾는다.
- 빈 검색창 포커스: 최근 본 산(설정 ON) + 계절·테마 키워드(설정 '추천 묶음' ON일 때만; 입력한 키워드 검색은 항상 지원).
- 명산 모드에서 타이핑하면 목록도 같은 검색어로 좁혀진다(기존 동작). Enter(제안 없이) = 목록 검색 확정.
- IME: keydown 맨 앞 `e.isComposing || e.keyCode===229` 가드. Esc = 제안 닫기 → 값 지우기, 둘 다 없을 때만 기본 동작(시트 닫기)을 허용.

## 7. 산 시트 `#/m/<id>`
```
│ ────                                        │
│ 설악산  1,708m             [등정 기록] [×]  │  제목 17/600
│ 강원 · 산림청·BAC·한국의산하 2위·월간산 5부문 │  13px  ← 여기까지 peek
│ 선택한 경로: 오색–대청봉           [보기][×] │  (경로를 고른 뒤 돌아왔을 때만, 고정)
│ [ 코스 6 ][ 주변 길 9 ][ 정보 ]             │  role=tablist, ←/→ 키
│ 주의 · 통제·예약 1건 · 위험구간 2건        › │  (경고 topic 있을 때만 → 정보 탭 현장 정보로)
├─────────────────────────────────────────────┤
```
- **코스 탭**: 등산로 행(504)에 `trail_index`로 연결된 대표 코스(277) 정보를 같은 행에 붙인다(코스명이 다르면 두 이름 모두 표시). 연결 없는 대표 코스(27)는 별도 행. 행 = 이름 · 들머리 · 거리 · 왕복 · 난이도 · 검증 수준 · 선 상태(수록 경로/계산 경로/지도 선 없음) · '공단 안내 확인/자료 선정'. 맨 아래 "OSM 등록 탐방로" 묶음(정상 300m 안을 지나는 kind=trail 노선). 설정 OFF 도구 안내 1줄("GPX 열기·경로 계획·겹쳐 보기는 설정에서 켤 수 있습니다 ›"). '여러 경로 겹쳐 보기' ON이면 행마다 선택 상자. '내 GPX 파일 열기' ON이면 탭 끝에 [GPX 파일 열기].
- **주변 길 탭**: 이 산의 걷기길(정상·들머리 기준 직선거리) 가까운 순. [5km][10km][15km] (기본 10). 탭을 열면 그 선들을 종류색으로 얇게 그리고 지도를 맞춘다. 행 = 색 견본 + 이름 + 종류 글자 + 순환/편도 + "이 범위 20.5km (전체 270km)" + "정상·들머리에서 9.8km". 정상 근처 kind=trail은 여기 넣지 않는다(코스 탭).
- **정보 탭**: 교통·주차 → 현장 정보(교차검증 후기, 경고 topic 먼저, 확인일·출처) → 개요·추천 계절 → 특징 태그(누르면 검색) → 목록 근거(접힘: 한국의산하 순위·월간산 부문 + 재집계 안내) → 출처(접힘) → 안내(자동 정리 자료 · 산행 전 공식 통제 확인 · 좌표 신뢰도).
- 지도: 산으로 이동(보이는 영역 가운데), 정상 라벨, 다른 산 기호는 유지.

## 8. 경로 시트 `#/m/<id>?route=…`
```
│ ‹ 설악산   오색–대청봉                   [×] │
│ 5.0km · 오름 4시간 · 왕복 8시간 · 어려움      │
│ 계산 경로 · 교차검증 일치                     │  ← peek
│ [들머리 길찾기] [GPX 받기]                     │
├───────────────────────────────────────────────┤
│ 고도 단면 120px(누르고 끌면 지도에 점) · 오름 누적·최고 │
│ [기본 | 대안 1]                                 │
│ 경유: 오색 → 설악폭포 → 대청봉 (대표 코스, 공단 안내 확인 2026-10-03) │
│ 선 출처: OpenStreetMap 등산로망 위 계산 · 실측 기록 아님 │
│ [따라가기]* [이 길로 계획]*                      │  * 설정 ON일 때만
```
- **선 스타일은 생성 방식(provenance)으로 정한다**, 파일 위치가 아니다: `recorded`(기증·실측 GPX `gpx/<id>.gpx`) 실선 · `osm-routed`(구운 계산 경로) 점선+"계산 경로" · `osm-relation`(OSM 노선) 실선+"OpenStreetMap 노선" · `user-file`(내 GPX) 실선+"내 파일" · `planned` 굵은 주황+"내 계획". 선택 순서: recorded > osm-routed(accepted) > osm-routed(review, "검토 필요") > 없음.
- 선이 없으면: 들머리 점 + "지도 선 없음". 설정 '등산로망 실시간 조회' ON일 때만 [실시간으로 길 찾기(느림)]. **직선 참고선은 그리지 않는다.**
- 지도: 선택 선 굵게(외곽선) + 들머리·정상 라벨 + 주요 봉우리 라벨. 다른 코스 선은 숨김(겹쳐 보기 OFF 기준).
- 들머리 길찾기: `trailhead_conf==='high'`만 좌표 목적지(카카오맵·자동차·대중교통), 아니면 장소 검색. 정상으로 자동차 안내 금지(기존 유지).
- GPX 받기: 선이 있을 때만. 계산 경로 파일은 desc에 고지(기존 파일 그대로).
- [‹ 설악산]으로 돌아가면 선은 남고 산 시트 위에 "선택한 경로" 고정 줄이 생긴다([×]로 해제).
- 경로 따라가기(설정 ON): 편도는 끝점, 순환은 출발점 복귀 기준. 이탈 ±40m 경고(기존 navInfo).

## 9. 걷기길
- **데이터**: `public/data/trekking/m/<id>.json`(산별: 정상·들머리 기준 15km 안 노선) · `index.json`(산별 개수·종류) · **`walks.json`(전국 노선: 전국 OSM `route=hiking|foot` relation 전부 + 산 주변 이름 붙은 길; rid·이름·kind·순환/편도·길이·bbox·가까운 명산[{id,km}]·거친 선(≈80m 단순화))**. walks.json은 지역 단위로 쪼개 필요할 때 받는다(`walks/<tile>.json`, 1° 격자), 목록 메타는 `walks-index.json`.
- kind: dulle(둘레길·자락길·걷기길·올레·해파랑 등 장거리 포함) · long(장거리: nwn/iwn 또는 올레·해파랑·남파랑·서해랑·평화누리·코리아둘레길) · ridge(대간·정맥·기맥) · forest(숲길·옛길·계곡·황톳길·산책로) · trail(코스·등산로·탐방로 이름의 노선) · other.
- 순환/편도: OSM `roundtrip` 태그, 없으면 시작·끝 200m 이내면 순환.
- **걷기길 시트 `#/walk/<rid>`**: 제목 · "둘레길 · 순환 · 이 범위 20.5km (전체 m km)" · "OpenStreetMap 노선 · 운영·통제 상태 미확인" · [카카오맵에서 위치 보기](장소 표시, 자동차 목적지 자동 지정 안 함) · [GPX 받기](표시 구간, desc 고지) · [OpenStreetMap에서 보기]. half: 고도 단면(누를 때 조회) · 지나는/가까운 명산 · 같은 이름 다른 구간 · 출처 relation 번호(ODbL). 둘레길이라는 이유로 '쉬움'·시간 추정을 붙이지 않는다.
- **걷기길 모드**(칩 [걷기길]): 지도 범위 안 노선 목록, 종류 필터 칩 [전체][둘레길][장거리][마루금][숲길·옛길], 지도 이동 후 [이 지역 다시 찾기]. 행 = 견본·이름·종류·순환/편도·길이·가까운 명산.
- 선 색(견본·지도에만): 정상 코스 적갈 `#b4432b` / 둘레길 청록 `#1f7a74` 4px / 장거리 남색 `#2c5d9e` 4px / 마루금 갈색 `#6b4e2e` 5px / 숲길·옛길 청록 3px 투명 0.7 / OSM 탐방로 녹색 `#3f7d3a` 3px. 다크 모드 짝 색(명도 상향). 종류는 색 + 굵기 + **글자 라벨**로 구분.
