# 조율안 v1 — 지도 한 장 위의 시트 (세 제안 종합)

세 제안서(A = 설계자 1, B = 설계자 2, C = 설계자 3)를 비교해 결정한 내용이다.
A/B/C는 각각 `proposal-a.md` / `proposal-b.md` / `proposal-c.md`.
각 결정 옆 괄호는 그 안을 낸 쪽이다. "다수"는 3안 중 2안 이상.

## 0. 세 안이 이미 합의한 것 (그대로 채택)

1. 첫 화면 = 전국 지도. 홈 대시보드(4,423px) 폐지, `#/`와 `#/map` 통합. 목록/지도 토글 제거. (A·B·C)
2. 목록은 지도 위 **비모달 바텀시트**(peek/half/full). 필터·레이어는 **모달 시트**. (A·B·C)
3. 산을 고르면 지도는 그대로 두고 시트 내용만 바뀐다. 마커 탭은 페이지 이동이 아니라 산 시트 열기. (A·B, C는 half 요약)
4. **경로를 지도에 띄우는 단일 진입점**: 경로 행(또는 지도 위 선)을 누르면 → 그 선이 그려지고 → 같은 시트에 거리·시간·난이도·검증·고도·길찾기·GPX가 따라온다. 현재 4곳(지도·고도 버튼, 대표 코스, 등산로별 고도, 코스별 GPX)을 하나로. (A·B·C)
5. 주변 걷기길은 지도 레이어 + 산 시트 섹션 + 걷기길 상세의 세 곳에서 같은 데이터를 쓴다. 종류는 색만이 아니라 **글자 라벨**과 선 굵기/모양으로 구분. (A·B·C)
6. 고급 도구는 설정에서 켜고 기본 OFF: 경로 계획, GPX 여러 개 열기, 경로 따라가기, OSM 등산로 실시간 조회, 여러 경로 겹쳐 보기. (A·B·C)
7. 테마 토글은 설정으로. 장식 히어로·등고선 카드·장식 통계·슬로건 제거. 이모지 아이콘 금지(단색 SVG + 글자). 카드 그리드 대신 행+구분선. 그라데이션·글래스 금지. (A·B·C)
8. 정직성 표시(계산 경로·교차검증·출처·현장 통제)는 끌 수 없다. 위치와 시각적 무게만 조정. (A·B·C)
9. 데스크톱 ≥1024px: 왼쪽 400px 패널(시트와 같은 내용) + 오른쪽 지도. (A·B·C)
10. 기존 딥링크 전부 해석(`#/map?…`, `#/m/<id>?course=`, `#/courses?…`, `#/stats`). (A·B·C)

- 지도 컨테이너는 화면 전체. 시트 높이만큼 지도 패딩(fitBounds 하단 여백)을 준다.

- 시트를 끝까지 내리면(44px, 그래버만) "지도만 보기".

### 2.2 목록 시트 (명산 모드)
- 헤더: "명산 31곳" + 적용 조건 토큰([강원 ×][BAC ×]) + "조건 초기화".
- 가까운 순일 때 헤더 아래 한 줄 "3분 전 위치 기준".
- 행(최소 60px, 구분선): 이름(동명이산 표기) · 해발 · 등정 표시 / 2행: 권역 · 대표 코스 한 줄(왕복 시간·난이도) · 거리(가까운 순일 때).
- 행 탭 = 산 시트(지도는 그 산으로 이동). 데스크톱 hover = 마커 강조.
- 설정 '추천 묶음' ON이면 목록 맨 위에 "인기·계절 기준 3곳" 묶음.

### 2.4 산 시트 `#/m/<id>`
```
│ 설악산  1,708m            [등정 기록] [×] │ 48
│ 강원 · 산림청·BAC·한국의산하 2위·월간산 5부문 │ 20 (13px)
│ [ 코스 6 ][ 주변 길 9 ][ 정보 ]            │ 44
│ 주의 · 통제·예약 1건 · 위험구간 2건       ›│ (후기 경고 topic 있을 때만)
├───────────────────────────────────────────┤
│ 오색–대청봉                              ›│ 코스 행
│ 오색 · 5.0km · 왕복 8시간 · 어려움          │
│ 교차검증 일치 · - - 계산 경로              │
```
- peek(160): 헤더 2줄 + 첫 코스 행. half: 탭 + 3–4행. full: 전체.
- **코스 탭**: 등산로(504) 행에 대표 코스(trail_index) 정보 병합 → 행 = 이름·들머리·거리·왕복·난이도·검증 수준·선 소스(수록/계산/없음)·'공단 안내 확인/자료 선정'. 연결 없는 대표 코스 27개는 별도 행. 맨 아래 "OSM 등록 탐방로"(kind=trail). 꺼진 기능 안내 1줄("GPX 열기·경로 계획은 설정에서 켤 수 있습니다 ›").
- **주변 길 탭**: 10km 안 걷기길, 거리순. [5km][10km] 전환. 탭을 열면 그 선들을 지도에 얇게(종류색) 그림. 행 = 색 견본 + 이름 + 종류 글자 + 이 산 구간 길이(전체 길이) + 정상에서 거리.
- **정보 탭**: 교통·주차 → 현장 정보(교차검증 후기; 경고 topic 먼저) → 개요·추천 계절 → 특징 태그(누르면 검색) → 목록 근거(한국의산하 순위·월간산 부문, 접힘) → 출처(접힘) → 안내(자동 정리 자료·공식 통제 확인).
- 등정 기록 버튼은 기존 `editHike` 재사용.

```
│ 고도 단면 120px (누르고 끌면 지도에 점)        │ half
│ 오름 누적 1,333m · 최고 1,700m               │
│ [기본 | 대안 1]                               │
│ 경유: 오색 → 설악폭포 → 대청봉 (대표 코스)      │
│ 출처 · 확인일 · 계산 방법 한 줄               │
│ [따라가기]* [이 길로 계획]* [다른 경로와 겹쳐 보기]*  (* 설정 ON일 때) │
```
- 선 소스는 사용자가 고르지 않는다(1장 #9 순서). 선이 없으면 들머리 점 + "지도 선 없음" + [실시간으로 길 찾기(느림)].
- 지도: 선택 선 굵게 + 들머리·정상 라벨 + 주요 봉우리 라벨(기존). 다른 선은 숨김(겹쳐 보기 OFF 기준).

### 2.6 걷기길 시트 `#/walk/<rid>`
```
│ ‹ 지리산   지리산둘레길 (인월-금계)       [×] │
│ 둘레길 · 이 범위 20.5km · 정상에서 9.8km     │
│ OpenStreetMap 노선 · 운영·통제 상태 미확인     │
│ [가까운 지점 길찾기] [GPX 받기] [OSM에서 보기] │
├──────────────────────────────────────────────┤
│ 고도 단면(요청 시 조회) · 지나는 명산 목록       │
│ 같은 길의 다른 구간(있으면) · 출처 relation 번호 │
```
- 둘레길이라는 이유로 '쉬움'을 붙이지 않는다. 시간 추정은 하지 않는다(데이터 없음).
- 잘린 장거리 노선은 "이 범위 n km (전체 m km)"로 따로 표기. GPX는 표시 구간만이며 파일 desc에 명시.

### 2.7 걷기길 모드 (칩 [걷기길])
- 지도: 화면 범위의 걷기길 선 전부(종류색), 산 기호 30% 흐림.
- 시트: "이 지역 걷기길 38개" + 종류 필터 [전체][둘레길·자락길][장거리][마루금][숲길·옛길] + 행(색 견본·이름·종류·길이·가까운 명산).
- 지도 이동 후 자동 갱신하지 않고 "이 지역 다시 찾기" 버튼(B).

### 2.8 내 기록 `#/track` (전체 페이지, 지도 셸 숨김)
상단 바 `‹ 지도 · 내 기록 · 설정` → 12 / 149 (세리프 28px 한 곳) + 4개 목록 진행 표(막대, 카드 없음) → [다녀온 산 검색해서 기록 추가] → 등정 목록(검색·정렬·날짜 수정·삭제) → 접힘: 권역별 진행 / 백업·이전 / 기기 간 동기화(배포 설정 시) → "지도에서 아직 안 간 산 보기 ›" (`#/map?hiked=0`).

### 2.9 설정 `#/settings` (전체 페이지)

## 3. 상호작용 규칙
- 시트 단계: 그래버 `<button>` 탭/Enter/Space = peek→half→full→half 순환, ↑↓ 키로 단계 이동, `aria-label="시트 크기: 중간"`. 드래그는 그래버+시트 헤더에서만(본문은 스크롤). 놓으면 가까운 단계, 속도 > 0.5px/ms면 진행 방향 다음 단계. half에서 본문 위로 스크롤 시도 → full. full·scrollTop 0에서 아래로 끌면 half. `overscroll-behavior: contain`. `prefers-reduced-motion`이면 애니메이션 없이.
- URL이 시트 상태(목록/산/경로/걷기길)를 나타낸다. [×]·Esc·브라우저 뒤로 = 한 단계 위(경로→산→목록). 딥링크로 들어와 이전 기록이 없으면 replace로 상위. 시트 **높이** 변화는 기록에 쌓지 않는다.
- 시트는 한 번에 하나. 필터·레이어 모달은 본 시트 위에 스크림과 함께, 모달 위에 모달 금지.
- 빈 지도 탭은 선택을 풀지 않는다. 지도 드래그로 시트 단계가 바뀌지 않는다.
- 내용이 바뀌면 포커스를 시트 제목으로, 결과 수는 `aria-live="polite"`.
- 한글 IME: keydown 맨 앞 `e.isComposing || e.keyCode===229` 가드(기존 유지). Esc는 닫을 것·지울 것이 있을 때만 `preventDefault`.
- 위치: 첫 실행에 묻지 않는다. [내 위치] 1회 탭 = 한 번 측정·이동, 다시 탭 = 실시간 추적 토글. 권한 허용된 재방문자만 조용히 측정. 기존 `position.js` 캐시 재사용.
- 터치 타깃 44×44 이상, 주요 버튼·검색 48.

## 4. 시각 언어
- 토큰: 기존 field-guide 팔레트 유지(`--bg #f7f6f0`, `--surface #fffef9`, `--text #233c32`, `--accent #315943`, 다크 `#17231e`…). `style.css`의 옛 토큰(radius 14, 그림자, `#2f7d4f`)은 정리. CSS는 토큰·셸·시트·목록·상세·기록·설정으로 재구성.
- 글자: 시스템 한글 산세리프, 크기 12·13·15·17·20, 굵기 400·600, 자간 0, 줄간격 1.5, 숫자 `tabular-nums`. 세리프는 기록 큰 숫자 한 곳.
- 아이콘: 인라인 SVG(검색·레이어·내 위치·닫기·뒤로·설정·펼침), 20px, stroke 1.5, `aria-label`. 나머지는 글자 버튼.
- 표면: 시트 위 모서리 12px, 1px 윗선, 그림자 하나(`0 -2px 8px rgba(0,0,0,.08)`). 칩·버튼 반경 6px. 목록은 행+구분선, 카드·그림자 없음.
- 선 색(지도와 견본에만): 정상 코스 적갈 `#b4432b`(계산 경로는 같은 색 점선), 둘레길·자락길 청록 `#1f7a74` 4px, 장거리 남색 `#2c5d9e` 4px, 마루금 갈색 `#6b4e2e` 5px, 숲길·옛길 청록 3px 투명도 0.7, OSM 탐방로 녹색 `#3f7d3a` 3px. 다크 모드 짝 색 별도.
- 문구: 제목은 명사, 버튼은 동사구 2–6자. 고정 정직성 문구: 검증 '교차검증 일치 / 자료 간 이견 / 단일 출처', 선 '수록 경로 / 계산 경로 / 지도 선 없음', 코스 근거 '공단 안내 확인 / 자료 선정', 걷기길 'OpenStreetMap 노선 · 운영 상태 미확인'.
- 하지 말 것: 이모지(◐ ◎ ⏳ 🎯 🚫 ⚠️ ⛶ 파비콘 ⛰️ 포함), 그라데이션, backdrop-filter, 큰 그림자, 슬로건·히어로·소개 문단, 카드 그리드, 섹션 설명 2줄 이상, 감탄·권유 문구("~해보세요!", "한눈에"), 같은 무게 버튼 3개 이상 나란히, 장식 통계(149·4·6·58), 의미 없는 색, 장식 일러스트, "스마트·AI 추천" 표현.

## 5. 데스크톱 ≥1024px / 태블릿
- 상단 52px 바: 제목 · 기록 · 설정 · 원자료. 왼쪽 400px 패널 = 시트 내용(단계 대신 스크롤), 오른쪽 지도(+확대 버튼). fitBounds 왼쪽 여백 0.
- 640–1023px: 바텀시트 최대 폭 560px, 왼쪽 16px.

## 6. 데이터 (주변 걷기길)
- `public/data/trekking/m/<id>.json`: 산별 반경 12km 노선(relation + 이름 붙은 길), kind, 이 범위 길이, 전체 길이, 정상 최단거리, 가까운 지점, 단순화 선, OSM 링크.
- `public/data/trekking/index.json`: 산별 개수·종류·상위 이름(목록 필터 '걷기길 있는 산', 주변 길 탭 숫자).
- `public/data/trekking/walks.json`(신규): 산별 파일을 rid로 합친 전국 고유 노선 목록 + 거친 선(≈60m 단순화) — 걷기길 모드·확대 레이어용.
- 출처 `© OpenStreetMap contributors (ODbL)` 표시.

## 7. 구현 순서
1. 기반: `prefs.js`, `icons.js`, 이모지 제거, 지도 계약 확장(점선·패딩 맞춤·범위/줌 조회·이동 이벤트·확대 버튼 토글·산 기호 스타일).
2. 지도 셸 + `sheet.js` + 목록 시트 + 필터/레이어 모달 + 라우터(지도 라우트는 셸 유지, 전체 페이지 라우트는 셸 숨김) + 딥링크.
3. 산 시트(코스/주변 길/정보) + 경로 시트(단일 진입점, 선 소스, 고도, 길찾기, GPX) + 설정 OFF 도구 연결(계획·GPX 열기·따라가기·겹쳐 보기·실시간 조회).
4. 걷기길: 데이터(`walks.json`), 주변 길 탭, 걷기길 모드, 걷기길 시트.
5. 기록·설정·대표 코스 모음 페이지, 데스크톱 패널.
6. 테스트 재작성(390/1440, 라이트/다크, IME, 키보드, 딥링크, 지도 실패), 화면 캡처 비교.

## 8. 위험
- 상주 지도로 바꾸는 리팩터링에서 늦게 온 응답이 다른 화면의 레이어를 건드리는 회귀 → 시트마다 레이어 그룹 + `disposed`/AbortController.
- 상세를 시트에 담는 부담(NN/g 경고) → URL·[×]·탭 3개·상단 바 유지.
- 모바일 제스처 충돌(iOS 툴바·당겨서 새로고침) → `dvh`, `overscroll-behavior`, 헤더에서만 드래그.
- 저작권 표시 가림 → 지도 저작권을 시트 윗변 위로 올림(시트 높이에 맞춰 이동).
- 기능을 잃었다고 느끼는 기존 사용자 → 원래 자리 한 줄 안내 + 딥링크 유지.
